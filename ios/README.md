# iOS-приложение «Студент−%» (SwiftUI)

Нативное приложение в дизайне «Концепция «Чек»» — то же, что мобильная версия сайта:
светлая и тёмная («тёплая тьма») темы, шрифты Unbounded / Manrope / JetBrains Mono,
пунктирные разделители, строки с отточием, бумажный чек с QR-кодом.

Ходит в тот же Go-бэкенд (`/api/v1/...`), что и сайт.

## Что есть

- Вход и регистрация, верификация студента (камера или галерея, превью, сжатие до 1600 px)
- Главная: «Вы сэкономили», поиск, теги, «Популярное рядом», все предложения, ивенты
- Предложение → оплата с кошелька или через СБП → чек с QR и кодом для кассы
- Заказы и журнал экономии (с экспортом CSV)
- Ивенты: лента по дням, страница ивента («Пойду / Может быть»), «Предложить ивент»
- Кошелёк (пополнение через СБП), рефералы
- Профиль, публичный профиль, друзья, подписки, уведомления (колокольчик со счётчиком)
- Поддержка: обращения и чат (ответы поддержки — красным)
- Настройки: профиль, приватность, уведомления, безопасность (сессии), аккаунт, тема

Сессия не слетает: access-токен обновляется через `/api/v1/auth/refresh`,
токены хранятся в Keychain.

## Сборка

Нужны Xcode 16+ и XcodeGen (`brew install xcodegen`).

```bash
cd ios
xcodegen generate
open StudentDiscountApp.xcodeproj
```

Дальше ⌘R на симуляторе или телефоне. Для телефона выберите свою команду
(Signing & Capabilities → Team).

## Адрес сервера

По умолчанию — `https://server.tailacb603.ts.net` (HTTPS через Tailscale; на телефоне должен быть
включён Tailscale). Поменять можно в приложении: на экране
входа долгое нажатие на логотип «СТУДЕНТ−%».

Для симулятора на том же Mac, где запущен docker-compose, удобно запускать
с аргументом `-server_base_url http://localhost` (Edit Scheme → Arguments).

```
StudentDiscountApp/
  Sources/

    Core/       API (токены, обновление), JSON, форматирование, геопозиция, фото

    Features/   экраны по разделам
  Resources/    шрифты, иконка, цвета
```
